# ענפים (Anafim)

מציג GEDCOM בעברית ובאנגלית — RTL/LTR, מותאם לנייד. אפשר לעבוד לגמרי במכשיר, או לסנכרן כספת מוצפנת בין מכשירים.

**גרסה 2.0 · עברית ↔ English**

## התחלה מהירה

1. פתחו את האתר (או `anafim.html` / build מקומי).
2. **פתיחת קובץ GEDCOM** → בחרו `.ged` / `.gedcom`.
3. השאירו **זיהוי אוטומטי** לקידוד; החליפו ידנית רק אם השמות משובשים.
4. חפשו אדם או לחצו על קרוב כדי למקד את התצוגה.
5. בסרגל: כפתור **עב / EN** להחלפת שפה (נשמר בדפדפן).

אין חובה בחשבון, בענן או באינטרנט לצפייה מקומית.

## מה יש כאן

- תצוגת אדם נבחר, הורים, סבים (מצד אבא / אמא), אחים ובני זוג
- חיפוש, אינדקס אנשים, ציר זמן ומקורות
- תמיכה ב־GEDCOM 5.5 / 5.5.1 / 7 (ליבה), קבצים עד ~30MB
- ממשק עברית + אנגלית, RTL ו־LTR
- **כספת ענן אופציונלית** — Google + הצפנה במכשיר (Passkey / סיסמה / מפתח שחזור); סנכרון בין מכשירים

**זה מציג, לא עורך:** אין עריכת אנשים או קשרים, אין שיתוף בין חשבונות.

## כספת ענן (בקצרה)

ההגדרה בפרודקשן כבר קיימת. למשתמש הקצה: התחברות Google → יצירת/פתיחת כספת → סנכרון.

הכספת ננעלת אחרי **יומיים** ללא פעילות באותו מכשיר (המפתח לא נשמר בדפדפן).

מי שצריך להקים פרויקט מחדש או לחפור:  
`supabase/migrations/202610180001_private_vault.sql` וקוד תחת `family-viewer/src/cloud-*.js`, `vault-*.js`.

## פיתוח

```bash
cd family-viewer
npm install
npm run dev      # http://localhost:5173
npm run build
npm test
```

פריסה: push ל־`master` → GitHub Actions → GitHub Pages.

## פרטיות

- קובץ GEDCOM מפוענח במכשיר.
- עותק מקומי בדפדפן (localStorage) הוא אופציונלי ולא מוצפן — לא מומלץ במכשיר משותף.
- בענן נשמר רק ciphertext; מפתח השחזור נשאר אצל המשתמש בלבד.
