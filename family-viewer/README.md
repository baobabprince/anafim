# ענפים — family-viewer

ממשק הווב של ענפים. לתיאור כללי של המוצר ראו את [README הראשי](../README.md).

```bash
npm install
npm run dev
npm run build
npm test
```

- קוד מקור: `src/`
- כספת / ענן: `src/cloud-*.js`, `src/vault-*.js`, `CloudAccess.jsx`
- i18n: `src/i18n/` (עברית + אנגלית)
- SQL לכספת: `../supabase/migrations/`
- מהמבט המשפחתי אפשר לבחור שני אנשים ולראות את שרשרת הקשרים הקצרה ביותר המתועדת ביניהם.
- תמונות: אפשר לבחור יחד קובץ GEDCOM ותמונות המדיה שלו, או להוסיף כמה תמונות לכל אדם מהמבט המשפחתי ולצפות בהן בגלריה. התמונות נשמרות מקומית במכשיר בלבד; תמונות מקושרות מזוהות לפי שם הקובץ, ותמונות שלא סומנו לשמירה נשארות זמינות למפגש הנוכחי בלבד. משפחת ההדגמה כוללת שבעה פורטרטים מאוירים מקוריים, שאינם תמונות של אנשים אמיתיים.

- ייצוא תרשים: במבט המשפחתי בחרו אדם ולחצו על ״תרשים להדפסה״. ניתן לבחור 3 עד 6 דורות של אבות ואימהות, לצפות בתוצאה, להוריד SVG או להדפיס / לשמור כ־PDF על A4 לרוחב. התרשים כולל אחים במשפחת ההורים שנבחרה, ואת בני הזוג והילדים בקשרי משפחה נפרדים, כאשר כל אדם מופיע פעם אחת. שאר הענפים משתמשים במשפחת הלידה או במשפחה הראשונה. קשרים חסרים לא מומצאים, ואחים ממשפחות הורים אחרות אינם מוצגים. הנתונים מעובדים במכשיר, אך קובץ ה־SVG או ה־PDF שתשמרו מכיל מידע משפחתי ויש לשמור עליו בהתאם. במשפחות גדולות ההדפסה על דף יחיד עשויה להיות קטנה.

- בחלון ייצוא התרשים אפשר להוסיף ענפים צדדיים: אחים של האדם הנבחר ושל אבותיו במשפחת ההורים שנבחרה, ובני זוגם וצאצאיהם (עד שלושה דורות צאצאים). עיגול מציין משפחה וחץ מצביע על ילד; חציית קווים ללא עיגול אינה קשר. ניתן להגדיל את התצוגה המקדימה או את ה־SVG, שכן תרשימים גדולים עשויים להיות קטנים בהדפסה על דף A4 יחיד.
