# ענפים — family-viewer

ממשק הווב של ענפים. לתיאור כללי של המוצר ראו את [README הראשי](../README.md).

```bash
npm install
npm run dev
npm run build
npm test
```

- קוד מקור: `src/`
- כספת / ענן: `src/cloud-*.js`, `src/vault-*.js`, `CloudAccess.jsx`
- i18n: `src/i18n/` (עברית + אנגלית)
- SQL לכספת: `../supabase/migrations/`
