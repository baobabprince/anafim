# ענפים — מציג GEDCOM פרטי בעברית (1.3.0)

מציג אילן יוחסין המותאם לנייד, לתצוגה לאורך ולכתיבה מימין לשמאל. מבט משפחתי מחובר עם כרטיס מרכזי מודגש, הורים מפורטים, בועות קרובים קומפקטיות ולוח מידע עם פרטים, ציר זמן ומקורות.

## שימוש מיידי

- בתצוגה החיה: לחצו על **פתיחת קובץ GEDCOM**. בנייד ניתן להשתמש בכפתור **פתיחת קובץ** בתפריט התחתון.
- אפשר לפתוח את `anafim.html` בדפדפן מודרני, ללא התקנה, ללא שרת וללא חיבור לאינטרנט. הקובץ העצמאי כולל את כל הקוד, הגופנים וקורא ה־GEDCOM.
- משפחת לוין שמופיעה בפתיחה היא **משפחה בדויה לצורכי הדגמה**. כל אדם, רישום ומקור בה מומצאים; המקורות מסומנים במפורש כבדויים.

## מה עובד

- פתיחת קובצי `.ged` ו־`.gedcom` עד 30MB; קובצי טקסט המכילים GEDCOM מתקבלים גם הם.
- קריאת רשומות הליבה של GEDCOM בגרסאות 5.5, 5.5.1 ו־7: אנשים, משפחות, שמות נוספים, תאריכים, מקומות, אירועים, עיסוק, הערות ומקורות.
- זיהוי UTF-8, UTF-16, ANSEL וקידודי Windows, עם בחירת קידוד ידנית לתיקון שמות משובשים.
- הורים מפורטים, בחירת משפחת לידה או משפחה מאמצת, וניווט בלחיצה.
- **סבים וסבתות מוצגים כברירת מחדל** בכרטיסים עם שמות מלאים, שנות חיים ומקום לידה. הם מחולקים לפי **מצד אבא / מצד אמא**, עם שם ההורה וקו חיבור ישיר אליו.
- במחשב רחב מוצגים ארבעת כרטיסי הסבים בשורה; בנייד נשמרות שתי קבוצות קריאות לאורך, בלי גלילה אופקית. כפתור **סבים וסבתות** מאפשר לצמצם ולהחזיר את הדור.
- מידע חסר על סבים מצוין במפורש, בלי ליצור אנשים מומצאים. אם להורה יש כמה משפחות הורים, אפשר לבחור איזו משפחת סבים להציג. לחיצה על כל שם עוברת למבט שלו.
- תאריכי לידה ופטירה מלאים, מקומות ועיסוק בכרטיסי ההורים; תאריך ומקום נישואים גם בכרטיס האדם הנבחר.
- לשוניות **פרטים / ציר זמן / מקורות**: שמות נוספים, מגורים, תכונות מתועדות, הערות, אירועי אדם ומשפחה, כותרות מקורות, מחברים, מראי מקום וציטוטים כשקיימים בקובץ.
- סיכום ייחודי של אנשים בדורות קודמים וצאצאים, עם רשימת ניווט מדורגת ובטיחות מפני מעגלים וקשרים כפולים.
- חישוב גיל בפטירה רק כאשר שני התאריכים מלאים ומדויקים; אין הסקת מצב חיים או השלמת מידע חסר.
- פתיחת רשומת האדם המקורית בתוך לשונית המקורות.
- ילדים, בני זוג, אחים ואחים למחצה ברשימות מתקפלות; תמיכה ביותר ממשפחת זוגיות אחת.
- חיפוש לפי שם, שם נוסף, מקום, שנה או מזהה רשומה. תמיכה במקלדת: `/` לחיפוש, חצים לבחירה, Enter לפתיחה ו־Escape לסגירה.
- אינדקס כל האנשים, סינון ומיון; טעינה מדורגת של תוצאות כדי לא להכביד על המכשיר.
- היסטוריית ניווט ואנשים שנצפו לאחרונה, אירועי חיים, הערות, פרטי קובץ ואזהרות לגבי קישורים חסרים.
- הדפסה ל־PDF דרך חלון ההדפסה של הדפדפן. ההדפסה מציגה את המשפחה הממוקדת, ללא תפריטי הממשק, ופותחת את רשימות הקרובים.
- הורדת קובץ GEDCOM ב־UTF-8 תוך שימור הטקסט המקורי והשדות שלא הוצגו.

זהו **מציג**, לא עורך GEDCOM. אין חילוץ אילן מ־PDF, אין חיבור לחשבונות חיצוניים ואין עריכת אנשים או קשרים. קובצי מדיה חיצוניים שאליהם מפנה GEDCOM אינם נטענים.

## פרטיות

אין צד שרת, אין חשבון, אין שירות אנליטיקה ואין שליחה של הקובץ לרשת. העיבוד מתבצע ב־Web Worker כשאפשר. אם הדפדפן או התצוגה המוגנת חוסמים אותו, היישום עובר אוטומטית לפענוח ישיר ומקומי בדפדפן, במקטעים המאפשרים לממשק להגיב. הגופנים והאייקונים מקומיים.

ברירת המחדל היא שמירה בזיכרון למפגש הנוכחי בלבד. תיבת **לזכור את הקובץ במכשיר הזה** מאפשרת שמירה ב־localStorage בדפדפן, בכפוף למגבלת האחסון שלו. אם אין מספיק מקום, האילן עדיין נפתח למפגש הנוכחי. ניתן למחוק את העותק השמור מתוך **פרטי הקובץ**. במכשיר משותף עדיף לא להפעיל זכירה.

פתיחת HTML מקומי נתמכת בדפדפנים מודרניים. ביישומי תצוגה מקדימה ובדפדפנים משובצים עשויות להיות מגבלות על הורדה, הדפסה ואחסון; לפתיחת חלון הדפסה או לשמירת קובץ יש להשתמש בדפדפן מלא או בתצוגה החיה. החל מגרסה 1.1 חסימת Web Workers אינה מונעת טעינת GEDCOM: מופעל גיבוי ישיר אוטומטי.

## פיתוח

דרוש Node.js 20 ומעלה.

```bash
npm install
npm run dev
```

שרת הפיתוח מוגדר להאזין ל־`0.0.0.0:5173` ולהתיר את כתובת סביבת התצוגה המקדימה. כל כתובות המשאבים הן יחסיות לאותו אתר; אין כתובות localhost בקוד הדפדפן.

```bash
npm test                 # בדיקות יחידה של קורא GEDCOM
npm run build            # הפקת אתר סטטי לתיקיית dist
npm run preview          # תצוגת גרסת הייצור
npm run standalone       # הפקת HTML עצמאי בתיקיית האב
```

### בדיקות דפדפן

```bash
npx playwright install --with-deps chromium
# הכנת ה־HTML העצמאי, שגם הוא נבדק:
npm run standalone
# במקביל לשרת הפיתוח:
npm run test:e2e
```

הבדיקות מכסות פתיחת קבצים אמיתית דרך בורר הקבצים, קידוד עברית, פרטיות ללא POST, זכירה ומחיקה, חיפוש, ניווט משפחתי, רשימות מתקפלות, הורדה והדפסה. הן רצות בתצוגת מחשב ובתצוגת נייד, ובודקות היעדר גלילה אופקית ברוחבי 320–1440 פיקסלים. נבדקים גם תאריכים מלאים, סבים המוצגים כברירת מחדל, קווי חיבור מדויקים, צמצום ופתיחה, בחירת משפחת סבים חלופית ומידע חסר, ניווט מבועות סגורות, מקורות, הרשומה המקורית, גיל מדויק ונגישות של לשוניות ורשימות פתוחות. קורא הקבצים נבדק גם מול קשרים חסרים, מזהים כפולים, מעגלים ואילן גדול.

## מבנה

- `src/gedcom.js` — פענוח קידודים, קורא רשומות, קשרים, תאריכים וסטטיסטיקה.
- `src/gedcom.worker.js` — ייבוא קבצים מחוץ ל־UI thread, כשהדפדפן מתיר זאת.
- `src/import-gedcom.js` — קריאת קבצים, גיבוי ישיר אוטומטי, טיפול בחסימות Worker, זמני המתנה וביטול.
- `CHANGELOG.md` — תצוגת הסבים והסבתות ב־1.3.0, שדרוג העיצוב ב־1.2.0 ותיקון טעינת הקבצים מ־1.1.0.
- `src/App.jsx` — ממשק, ניווט, חיפוש, פתיחת קבצים, פרטיות והדפסה.
- `src/FamilyExperience.jsx` — האילן המחובר, כרטיסים, קרובים, לשוניות מידע וסייר ענף.
- `src/person-info.js` — איחוד אירועים ומקורות, חישוב גיל מדויק וספירת דורות ייחודית.
- `src/ancestry.css` — כרטיסי סבים ברורים, חלוקה לצדדים, קווי דורות ותצוגה מותאמת לרוחב האילן.
- `src/family.css` — עיצוב חלל המשפחה, שיפורי המעטפת ותצוגות נייד והדפסה.
- `src/styles.css` — עיצוב RTL רספונסיבי, גופנים מקומיים, נגישות והדפסה.
- `src/demo.js` — קובץ GEDCOM בדוי עם 24 אנשים, 9 משפחות וחמישה דורות.
- `scripts/standalone.mjs` — הטמעת כל המשאבים ו־Web Worker בקובץ יחיד.
- `tests` — בדיקות יחידה ובדיקות דפדפן.

היישום משתמש ב־React, Vite ו־Lucide, ובגופני Heebo ו־Noto Serif Hebrew. רישיונות הגופנים מצורפים בתיקיית `licenses`; רישיונות חבילות צד שלישי נמצאים בהפצות החבילות.

## תיקון הטעינה בגרסה 1.1

בגרסה הקודמת הדוגמה המובנית נפתחה ללא Worker, אך מסלול העלאת הקבצים דרש Worker. בתצוגות מוגנות הדבר גרם לדוגמה לעבוד ולקבצים תקינים להיכשל. כעת אותו קורא GEDCOM עובד גם במסלול ישיר שאינו דורש Worker, בקובץ העצמאי וגם באתר. בדיקות הרגרסיה מעלות קבצים חיצוניים אמיתיים דרך בורר הקבצים לתוך iframe בעל `worker-src 'none'` וללא גישה לרשת.

אם קובץ מסוים עדיין אינו נפתח, הודעת השגיאה כוללת קוד טכני שאפשר למסור בלי לחשוף מידע משפחתי. פירוט מקור קובצי הבדיקה ורישיונותיהם נמצא ב־`tests/fixtures/public/README.md`.
